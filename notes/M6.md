# M6 — AI Tools Landscape

_Cohort notes for the M6 module._

## Copilot

Copilot completes the next token based on surrounding code patterns — it has no awareness of CLAUDE.md, project conventions, or what the tests say, so it's fast at boilerplate but will confidently suggest code that violates rules it never read.

## Chat

Pasting the M5 task 1 diff into chat for review, it caught that the tags input uses `{{ tags_value or '' }}` but the re-render on validation error only passes `title`, `body`, and `errors` back — never `tags_value` — so the tags field silently clears on error while title and body are preserved, an inconsistency a junior reviewer should flag before merge.

## Gemini CLI

Both tools navigated the codebase at the same speed and described the Flask structure accurately, but Claude Code's answer included the cohort workflow and task conventions from CLAUDE.md while Gemini CLI's answer treated the repo as a generic Flask app — same interface shape, the difference shows up exactly where project context matters most.

## Tool decision matrix

| Situation | Tool I'd reach for | Why |
|---|---|---|
| Multi-file feature with good CLAUDE.md | Claude Code | Reads project conventions, enforces guardrails, plan-first |
| 5-line helper autocomplete while typing | Copilot | Inline, zero context-switch, fluency beats brief-writing |
| Brainstorm three design approaches | Chat (claude.ai) | No code investment, pure reasoning, easy to redirect |
| Review someone else's PR diff for risks | Chat (claude.ai) | Paste diff cold, independent read without project baggage |
| Propose a multi-file refactor to review visually | Cursor Composer | Inline diff in editor before touching anything |
| Same task, want a second model opinion | Gemini CLI | Same interface shape, different model — useful calibration |

## Cursor

Cursor's Composer is the right reach when you want to see a multi-file diff proposed inline before committing to it — the visual review in the editor is faster than reading terminal output — but Claude Code wins for anything that needs project-wide context, a plan-first conversation, or rules enforced via CLAUDE.md.
